## 미결 (sender 작성)
owner 지적(2026-10-11, 밤새 처리 지시): K-ICS.html 에서 **스위스리·스코리 등 재보사는 「자본비율 Forward Outlook 없음」으로 표시**된다. owner: 「재보사가 **자본성증권 발행이 없는 건 그럴 수 있다.** 그래도 **스코리는 경과조치 적용사**라 Forward Outlook 에서 **우하향 패턴이 딱 보여야 한다.** **재보사들도 Forward Outlook 이랑 자본성증권 인정한도 소진율 다 채워놔라.**」

### 배경
- K-ICS.html 하단 두 패널: **자본성증권 인정 한도 소진율**(도넛, 데이터 `data/bonds/capital_securities_utilization_*.json` 등)과 **자본비율 Forward Outlook**(2026~2030 보수 시나리오, 데이터 `data/bonds/capital_securities_forward_outlook.json`, 빌더 `scripts/forward_capital_simulation.py`; 분모 = 지급여력기준금액을 적용후→적용전으로 2032 까지 선형 보간, 분자 = 이미 발행한 자본성증권을 콜 도래 5년차에 가용자본에서 차감). 페이지 코드는 `forwardSimData` 에서 회사명으로 행을 찾는다(`findForwardRow(companyName)`, 이름 일치/부분 포함).
- 재보사 8곳(KR1101~KR1108)은 최근에 마스터에 들어와서 위 빌더들이 돌 때 코호트에 없었을 가능성이 높다. 빌더 docstring: 「Universe = DART bond cohort ∪ K-ICS baseline cohort. 채권 없는 보험사는 flat SCR-interp 투영(bond_coverage=no_bonds)」 — 즉 **K-ICS 기준선만 있으면 채권이 없어도 투영이 만들어져야 한다.** 또 K-ICS.html 이 회사명 약칭(재보사 이름 축약: 뮌헨·제네럴·RGA 등)을 쓰므로 **약칭 때문에 `findForwardRow` 이름 매칭이 깨졌는지**도 확인한다(원인이 데이터 부재인지 이름 불일치인지 둘 다 본다).

### 해 줄 것
1. **원인 확인**: 재보사 8곳이 forward outlook / 소진율 데이터에 있는지(없으면 왜 제외됐는지: 코호트 필터·PAA 전용 제외 규칙·분기 인자·이름 불일치), K-ICS.html 이 어떻게 「없음」을 표시하는지 코드·라이브 데이터로 재현(`?iq_internal=1`).
2. **재보사 8곳의 Forward Outlook 생성**: 최신 기준분기(K-ICS.html 이 쓰는 분기, 현재 2026.2Q) 마스터에서 `scripts/forward_capital_simulation.py`(분기 인자 `--baseline-quarter`/`--tier-quarter` 확인)를 돌려 재보사가 포함된 `capital_securities_forward_outlook.json` 을 만든다. **기존 39사 행은 값이 바뀌면 안 된다**(전후 diff 로 증명; 최신 분기 기준으로 다시 돌리는 것이라 기준분기가 바뀌면 기존 회사 행이 바뀌는 게 정상인지 먼저 확인하고, 바뀌면 현재 라이브 파일과 같은 기준분기·같은 인자로 돌려 재보사 행만 더한다). 시뮬 입력(적용후/적용전 지급여력기준금액)은 **경과조치 적용사만 우하향 패턴이 나와야 한다: 스코리(KR1106)는 요구자본 경과조치 적용사**(`_TRANSITION_APPLIERS` 편입, 값_적용후 ≠ 값)이므로 SCR 이 2025→2032 에 선형으로 늘어 비율이 내려가는 곡선이 나와야 하고, 다른 재보사(경과조치 비적용)는 flat 이어야 한다. 결과를 검산: 스코리 곡선의 시작점 = K-ICS 지급여력비율(적용후), 끝점 = 2032 적용전 기준 비율.
3. **재보사 8곳의 자본성증권 인정한도 소진율**: 재보사는 DART 사업보고서가 없고(지점) 자본성증권 발행이 없는 곳이 대부분. 마스터(`kics_disclosure.json` 의 기본자본 자본증권·보완자본 후순위 항목들)에서 발행/한도가 있으면 소진율을 계산하고, **발행이 없으면 소진율 0% 로 채운다**(「n/a」가 아니라 「발행 없음 = 0%」 표기가 화면에 맞는지 K-ICS.html 도넛 코드를 보고 맞춘다). 근거(발행 없음 = 공시 항목 0 또는 해당 표 없음)를 provenance 에 기록하고, **소진율 마스터·provenance 스크립트**(`scripts/wire_capital_securities_to_utilization.py`·`build_capital_securities_recognition.py`·`emit_capsec_provenance.py`·`derive_capital_ratios.py` 중 맞는 것)로 재보사 행을 더한다. 원천이 마스터에 실제로 값이 있는 재보사(예: 후순위·신종자본증권이 있는 지점)가 있으면 그 값을 쓴다 — 지어내지 않는다.
