### Q-2. 한화손해보험 17BS 2026.2Q — 소스가 있는데 마스터에 없다 (판정 필요)

17BS 2026.2Q 는 12사뿐이고 나머지 12사가 빈다. 11사는 **정상 부재**(FS-API 2026/11012 가
OFS·CFS 둘 다 `status=013` = 반기 XBRL 미제출. 본문 XML 은 있어서 CSM/PL 은 나온 것).
**한화손해보험만 다르다:**

```
KR0002 00135917 2026 11012 OFS : status=000, BS 4행
        → 무형자산·투자부동산·유형자산·사용권자산, thstrm_amount 전부 공란(빈 껍데기)
KR0002 00135917 2026 11012 CFS : status=000, BS 45행
        → ifrs-full_Assets 19,803,699,697,000 등 완전한 BS
```

`build_ifrs17_bs.py` 는 owner P-1(2026-08-14)에 따라 **BS 는 OFS 고정**인데, 이 케이스는
"OFS 가 틀린 값을 준다"가 아니라 **"OFS 에 자산/부채/자본이 아예 없다"** 는 다른 상황이다.
(흥국화재도 OFS 1행이지만 CFS 가 013 이라 소스 자체가 없다 → 정상 부재.)

**판정 요청**: OFS 에 항목1/2/3 이 전무할 때만 CFS 로 폴백하는 조건부 규칙을 넣을지.
넣는다면 P-1 이 막으려던 사고(삼성생명 CFS 가 1Q 값을 stale 복제)와 구분되도록
**"OFS 에 해당 항목이 없을 때만"** 으로 좁히고, 폴백한 셀은 provenance 에 basis=CFS 로
남길 것. 검증쪽 의견으로는 넣는 게 맞지만 **P-1 은 owner 결정이라 파서가 임의로 뒤집지 말고
owner 확인 후 진행**하길 권한다.
