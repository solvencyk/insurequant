### 4. Sanity check — "기초 대비 상식적 범위"는 잘못된 기준이었다

orchestrator 의 원 대사("2026.1Q 489.9 <- 상식적, 2023.4Q 14,574.1 <- 6배 이상")는 **모든
분기를 FY2025 의 기초(64,380.6억)로 나눠 비교**했는데, 이는 오류다 — 2023.4Q 의 실제 기초는
46,967.3억(FY2023 년초)이지 64,380.6억이 아니다. 자기 기초 대비로 다시 계산하면:

```
2023.4Q(연차, 12개월분) 14574.1 / 46967.3(FY2023 년초) = 31.0%   <- IFRS17 원년(2023) 첫 공시,
                                                                    공정가치 전환 재보정 변동 포함이라
                                                                    변동성 큰 첫해로는 설명 가능
2025.2Q(YTD 2분기분) 12197.0 / 64380.6(FY2025 년초)   = 18.9%   <- 반기 누계 기준, 연환산 아님
2026.1Q(YTD 1분기분)  489.9  / 65109.6(FY2026 년초)   =  0.75%  <- 1개 분기분
```
"연 3.5%"는 GMM lock-in 이자부리(고정금리 부리)에나 맞는 기준이고, 교보처럼 공정가치법
전환계약(위 §1의 -624,435백만 열)이 섞인 회사는 그 가정 자체가 안 맞는다 — 애초에 "정상 범위"의
정의가 틀렸다. 매 분기 부호·크기가 원문(§1)과 정확히 일치하므로 이 이상은 손댈 데가 없다.
