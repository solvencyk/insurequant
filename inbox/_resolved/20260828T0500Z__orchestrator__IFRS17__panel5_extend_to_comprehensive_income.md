### 스펙과 다르게 한 것 2건 (확인 요청)

**(1) `기타 포괄손익(미분류)` 잔차 막대를 하나 추가했다.** 티켓의 "25 는 26~30 의 합" 전제가
실데이터에서는 근사일 뿐이다 — 최신분기 기준 **ABL생명 154,075백만(총액의 58%)·코리안리
75,903백만(63%)** 이 세부에 안 잡힌다. 잔차를 안 그리면 브리지가 31 에 도달하지 못한 채 끊긴다.
그래서 25 는 여전히 막대로 안 그리되(중복 방지), `25 − Σ(26..30)` 이 **총액의 1% 이상이고 1억 이상일 때만**
29 바로 앞에 한 칸 넣었다. 기존 `기타(사업비용)` 스텝과 같은 성격이다. 삼성생명은 잔차가 미미해서 안 뜬다.
반면 `24 + 25 = 31` 은 전 36사·전 분기 오차 0으로 성립한다.

**(2) 🔴 인덱스 빌더의 null→0 버그를 고쳤다 (이 티켓의 결측 요구사항을 위해 필수).**
`ix.plx` 빌드가 `Number(r["값"])` 를 그냥 태우고 있었는데 `Number(null)===0` 이고
`Number.isFinite(0)===true` 라 **미공시 셀이 전부 진짜 0 으로 둔갑**하고 있었다. 실측 규모:
`값` null 1,347셀 · `값_당분기` null 2,377셀(그중 OCI 616셀). 이 마스터엔 진짜 0 도 836셀 있어서
0 과 결측은 반드시 갈려야 한다. 이걸 안 고치면 "결측을 조용히 0 으로 칠하지 마라" 는 요구가
구현 불가능하다. **화면에 보이는 변화 2가지** —
- 표의 미공시 칸이 `0` → `—` 로 바뀐다(예: 라이나생명 2023년 열).
- **분기(당분기) 모드에서 연1회 공시사 12사가 차트 대신 stub 으로 바뀐다.** 그 회사들은 latest 4Q 의
  `값_당분기` 가 원래부터 null 이라(3Q 누계가 없어 차분 불가) 이전엔 **전 항목 0 짜리 가짜 브리지**를
  그리고 있었다. 지금은 기존 문구 "해당 기간 당기순이익 데이터가 없습니다" 가 뜬다. 데이터 원문으로
  7개사 직접 확인함(AIG·라이나·AIA·IBK연금·악사·예별·신한EZ 전부 `값_당분기: None`).
  YTD 로 폴백할지 stub 으로 둘지는 표시정책 결정이라 owner/orchestrator 판단이 필요하다.
