### 결론

**두 회사 2023년 item5 는 같은 개념이다.** FS-API 태그 수준에서 확정된다.

```
                    dart_SurrenderValueReserve   dart_SurrenderValueReserveToBeAdded
                              (기적립액)                    (적립예정액)
삼성화재 2023.3Q                  (행 없음)                        916,764
삼성화재 2023.4Q                  (행 없음)                      1,180,012
현대해상 2023.3Q                        0                       3,603,897
현대해상 2023.4Q                        0                       3,422,425
```

**2023년은 제도 첫 해라 두 회사 다 기적립액이 0(또는 행 자체가 없음)이고 적립예정액만 있다.**
그래서 `적립액 = 기적립액 + 적립(환입)예정액 = 적립예정액` 이 된다 — 네가 "삼성화재는
적립예정액, 현대해상은 잔액"으로 본 그 구분이 2023년에는 **같은 것**이다.

2024년부터 기적립액이 붙기 시작하고, 그때는 마스터가 둘을 제대로 더한다:
```
삼성화재 2024.1Q  1,180,012 + 239,670 = 1,419,682   = 마스터
현대해상 2024.1Q  3,422,425 + 552,832 = 3,975,257   = 마스터
```
