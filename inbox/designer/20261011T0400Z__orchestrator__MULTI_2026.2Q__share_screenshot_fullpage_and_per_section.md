### 배경(코드 이력)
- 공유 메뉴(링크 복사·스크린샷)는 사이트 공통(`theme.js`·`common.css`)으로 2026-10-08 에 넣었다(커밋 8c997cb·1d6a7d6·eb7ea4f·0fd29a5 등: 「복제본 애니메이션 끄기·찍기 전 글꼴 대기·좁은 화면은 짧은 출처」). `git log -p -- theme.js` 로 **언제부터 전체 페이지 캡처가 현재 화면 캡처로 바뀌었는지**(예: 애니메이션/고정 헤더 문제 때문에 viewport 캡처로 바꿨는지, 모바일 높이 한도 때문인지) 먼저 찾아 원인을 적는다.

### 해 줄 것
1. **전체 페이지 스크린샷 복구**: 헤더 공유 메뉴의 스크린샷 = 페이지 전체(모든 섹션, 모바일에서도 긴 세로 이미지). 브라우저별 캔버스 최대 크기(특히 모바일 Chrome/Safari 의 캔버스 한계, 약 16,384px 또는 총 면적 제한)를 넘으면 **배율을 낮춰** 한 장으로 만들되 글자가 읽히는 해상도를 유지하고(필요하면 상한 안에서 `scale` 자동 조절), 그래도 못 넘는 매우 긴 페이지는 이어 붙이는 안을 제안만 한다. 고정 헤더·플로팅 버튼(오류 제보·햄버거 메뉴)·공유 메뉴 자체는 캡처에서 제외, 다크/라이트 현재 테마 유지, 입장 애니메이션 첫 프레임 문제는 기존 대응(복제본 애니메이션 끄기 등) 유지. **출처 표기**(회사 선택·기준 분기 포함, 이미 있으면 유지)를 이미지 하단에 넣는다.
2. **섹션별 공유 버튼**: K-ICS.html·IFRS17.html·compare.html 의 각 **섹션(패널·카드) 우상단**에 작은 공유 아이콘 버튼. 눌러 그 섹션만 이미지로 만들어 **공유(Web Share API 로 이미지 파일 공유, 안 되면 다운로드/클립보드 복사 폴백, 기존 헤더 공유와 같은 방식)**. 이미지 하단(또는 상단)에 **출처**: 「InsureQuant · insurequant.com · 자료: 금융감독원 정기경영공시·DART 전자공시 · 기준 분기(회사·분기 포함)」 정도(기존 헤더 스크린샷의 출처 문구와 같은 형식, 좁은 화면에서는 짧은 형식). 섹션 제목·선택 회사(예: 「IFRS17 · CSM 시계열 · 삼성생명」)가 이미지에 보이게 하고, 버튼 자체는 이미지에서 빠진다. 각 페이지의 **섹션 목록을 전수 확인**해 빠진 섹션이 없게 한다(K-ICS 패널들, IFRS17 섹션 1~9 와 접이식 표, compare 의 지표 카드들). 사별 비교는 **카드마다**(지급여력비율·기본자본비율·CSM·손해율 curve 등) 버튼. index.html 은 이번 범위 밖(헤더 공유만).
3. 접근성: 버튼 `aria-label`(「이 섹션 스크린샷 공유」), 키보드 포커스, 터치 영역 44px(아이콘은 작아도 타깃은 넓게), 다크·라이트 대비. 모바일에서 섹션 제목과 겹치지 않게(제목이 긴 섹션은 제목 우측 여백 확보).
4. 회사코드 이미지·주소 비노출(`feedback_company_codes_internal_only`), 음수 △ 유지. 외부 폰트·이미지 때문에 캔버스 오염(taint)되지 않게(CSP·SRI 규칙 `docs/agents/claude-agent-designer.md`·`reference_csp_sri_cdn_hardening` 참고; html2canvas/dom-to-image 류를 이미 쓰고 있으면 같은 라이브러리·같은 버전 고정 그대로 사용, 새 CDN 추가 금지).
