기본자본 자본증권 = 보통주 제외 자본증권 중 기본자본요건(스텝업 없음 등) 충족분. 항목 6 은 한도 전 계상액이라 **보완자본형(Ⅲ.2.다.(2)) 신종을 포함한 상한값**이다 - 보완자본형은 빼야 한다. 10% 가 원칙이고 15% 는 「보험업법」 조건부자본증권(보험사 발행 사례 없음)과 기발행분(경과조치, 2032 까지)만. 100% 초과는 정당(owner 2026-06 「발행/한도」 결정과 같음)하며 초과분은 보완자본으로 재분류된다(자본에서 사라지지 않음 - tier2 초과와 결과가 다르다). 자본증권이 없으면 0%.

- ? 팝오버(tier1): 「기본자본 자본증권 = 보통주를 제외한 자본증권 중 기본자본요건을 충족하는 자본증권. 인정한도 = 총요구자본의 10%(「보험업법」 조건부자본증권 15%), 2022년 이전 발행분은 2032년까지 15%(공통적용 경과조치). 한도 초과분은 보완자본으로 재분류. 근거: [별표22] Ⅲ.2.다.(1), Ⅵ.1.가.(1)」
- 표시 규칙: 분모가 있고 분자 0 → `0%` (규정상 정답). 그중 자본증권이 아예 없는 회사(항목 6 ≤ 0, 채권 없음) tier1 은 가운데 `0%` + 캡션 아래 작은 글씨 `발행 없음`(owner 결정 ⑱ 연장). tier2 가 0 인데 보완자본 > 0 이면 숫자 줄에 `보완자본 X억원은 전액 한도 계산 제외 항목` 대신 공시 표기 `해약환급금 부족분 상당액 중 해약환급금준비금 상당액 초과분 X억원` 을 그대로 보여 준다. 원문 부재 → 가운데 `—` + 툴팁 `경과조치 표 미공시` (현재 「데이터 없음」과 구분). 100% 초과 → 기존 `100%+` 유지, 툴팁만 tier1 「초과분은 보완자본으로 재분류」 / tier2 「초과분은 지급여력금액에서 불인정」으로 구분.
