# K-ICS Market Risk (시장위험액) Sub-Risk Decomposition — Research + Validation Rule

**Status:** research complete, ready for parser + validator implementation (2026-06-09).
**Source of truth (domain):** `新지급여력제도(K-ICS) 해설서` 제4장 시장위험액 (p.199–), 특히 `<표19> 시장위험액 하위위험 간 상관계수` (해설서 p.205).
**Analogous to:** Rule `8_life` (item17 = 생명장기손해보험위험액 = `sqrt(S'·R7·S)` over items 29–35). This doc does the same for **item19 = 시장위험액**.

---

## 1. What the standard says

시장위험액(item19)은 5개 하위위험으로 분해되고, 상관계수 행렬을 적용해 합산한다 (해설서 4-1.나):

| 하위위험 | 측정방식 | 비고 |
|---|---|---|
| 금리위험액 | 충격시나리오 (금리상승/하락/평탄/경사/평균회귀 5개 시나리오의 합성) | 공시값은 이미 시나리오 합성된 단일값 |
| 주식위험액 | 충격시나리오 | 경과조치(TER) 대상 — 경과조치 전/후 컬럼 주의 |
| 부동산위험액 | 충격시나리오 | 미보유사 → 행 자체가 없음(=0) |
| 외환위험액 | 충격시나리오 | |
| 자산집중위험액 | **위험계수 방식** | 상관계수 0 (타 위험과 무상관). 미보유사 → 없음(=0) |

**합산식:**

```
시장위험액(item19) = sqrt( V' · M · V )      V = [금리, 주식, 부동산, 외환, 자산집중]
```

(`8_life`의 `sqrt(S'·R7·S)`와 동일 구조. 음수 내적은 0으로 클램프 후 sqrt — 기존 헬퍼 재사용.)

## 2. The matrix M (`<표19>`, order 금리·주식·부동산·외환·자산집중)

```
          금리    주식    부동산   외환    자산집중
금리    [  1.00    0.25    0.25    0.25    0.00 ]
주식    [  0.25    1.00    0.25   -0.25    0.00 ]
부동산  [  0.25    0.25    1.00    0.25    0.00 ]
외환    [  0.25   -0.25    0.25    1.00    0.00 ]
자산집중[  0.00    0.00    0.00    0.00    1.00 ]
```

- **외환↔주식 = −0.25** (해설서 원문 `△0.25`). 국내 주식시장 외국인 비중이 커 환율 급등 시 외인 매도→주가 하락 추세를 반영(음의 상관). 이 음수 항이 시장위험액을 **낮추는** 분산효과의 핵심.
- 자산집중위험은 전 항목 상관 0 → 사실상 `sqrt(나머지4 분산합산식 + 자산집중²)`.
- Symmetric; 대각 1.0.

### 前/後 주의 (도출근거 행렬과 혼동 금지)

해설서 p.206에 같은 행렬이 `前/後` 컬럼으로 한 번 더 나오는데, 이는 **운영용 두 시나리오가 아니라 ICS 원안(前) → K-ICS 조정(後) 도출근거**다. 조정된 항목은 두 곳뿐:

| 쌍 | 前(ICS) | 後(K-ICS, 운영) |
|---|---|---|
| 주식·부동산 | 0.5 | **0.25** |
| 주식·외환 | 0.25 | **−0.25** |

**운영에 쓰는 행렬은 `後` 컬럼 = 위 §2 행렬 = `<표19>`(p.205).** 아래 골든테스트(169/188 정확 일치)가 `後` 행렬이 실제 공시값을 재현함을 실증한다 — 시나리오 선택/Max 없음, 단일 행렬.

## 3. 결정적: 공시 가용성 + 단위 함정

### 3-1. 공시 가용성 (검증 가능 확인)
정기경영공시 383개 MD 중 **197개가 시장위험 하위 5종을 숫자 표 행으로 공시**한다 (생명장기 29–35과 동일하게 분해 공시됨). 따라서 matrix-sum 검증이 **가능**하다.

단, **메인 요구자본표(item19)에는 시장위험액이 단일 라인으로만** 나오고, 하위 5종은 **별도 "시장위험액 세부내역" 표**에 있다 (생명장기는 메인표에 29–35가 같이 있는 것과 다름). 파서는 이 별도 표를 따로 떠야 한다.

### 3-2. 단위 함정 (★ 가장 중요)
- 메인 요구자본표 (item19 포함): **억원**
- 시장위험 세부표 (하위 5종 + 세부표 자체의 시장위험액 합계): **백만원**
- **1 억원 = 100 백만원.** 즉 `세부표 시장위험액(백만원) = item19(억원) × 100`.

실증 (흥국화재 FY2023_Q1):
- 메인표 item19 = `8,132` 억원
- 세부표 V = 금리 454,370 / 주식 518,709 / 부동산 106,870 / 외환 57,469 / 자산집중 0 (백만원)
- `sqrt(V'·M·V) = 813,201` 백만원 = `8,132.01` 억원 → item19와 **<0.01% 일치** ✓

## 4. Golden test (실증)

스크립트: `scripts/_probes/` (probe; 정식화는 validator가). 행렬 §2 그대로, V는 세부표 col0(경과조치 전), total은 세부표 시장위험액(백만원, 동일단위).

| 결과 | 건수 |
|---|---|
| 테스트된 (회사×분기) | 188 |
| 오차 <1% (사실상 반올림 수준 정확) | **169** |
| 오차 >3% (조사 필요) | 19 |

19건 실패는 **공식/행렬 실패가 아니라 파서 아티팩트**:
- `-99.9%` 류: 다기간 컬럼 병합/단위 오인(백만↔억), 셀 concatenation (예: 현대해상은 5종을 **한 셀에 공백구분으로 뭉쳐** 공시 → line: `시장위험액 금리위험 주식위험 ... 2,930,613 622,226 2,493,425 ...`).
- `+956%/+1414%/+5758%` 류 (한화생명·KB라이프): total 컬럼과 sub 컬럼의 **경과조치 전/후 짝 오선택**.
- `−24~−40%` 류 (에이비엘·메트라이프·라이나): 세부표가 분기별/경과조치별 다중 컬럼이라 **잘못된 컬럼쌍**을 집음.

→ 모두 §5 파서 가이드로 해소 가능. 행렬·공식은 변경 불필요.

## 5. Parser 가이드 (handoff → stage 2)

**목표:** 각 (회사, 분기)에서 시장위험 하위 5종을 추출해 disclosure JSON에 신규 항목으로 적재.

**제안 항목번호 (29–35 다음 이어서):**

| item | 항목명 | 미보유 시 |
|---|---|---|
| 36 | 시장위험액 중 금리위험액 | 0 |
| 37 | 주식위험액 | 0 |
| 38 | 부동산위험액 | 0 |
| 39 | 외환위험액 | 0 |
| 40 | 자산집중위험액 | 0 |

**단위 정규화:** 세부표는 **백만원**. disclosure JSON 표준단위(억원)에 맞추려면 **÷100**. (정밀도 손실 방지를 위해 백만원 원값을 별도 필드 `값_백만원`로도 보관 권장 — validator가 item19×100과 백만원 단위로 대조하면 반올림오차 최소.)

**라벨 변형:** `금리위험`/`금리위험액`/`금리위험 주)`, `자산집중위험`/`자산집중위험액`. 행두 매칭 시 `시장위험액`(합계행)과 구분(접두 `시장` 제외).

**컬럼 선택:** 세부표는 보통 `[경과조치 전 | 경과조치 후]` 또는 다기간. **주식위험만 경과조치(TER)로 전/후가 다름**; 나머지는 전=후. matrix-sum 검증은 **경과조치 전(=col0) 끼리** 짝지어야 일관. (현재 8_life·item17도 경과조치 전 기준.)

**concatenated-cell 회사 (현대해상 등):** 한 셀에 `라벨들 ... 숫자들` 공백구분으로 뭉친 경우 → 라벨 토큰 순서대로 숫자 토큰 매핑하는 별도 파서 분기 필요.

**미보유 처리:** 행이 없으면 해당 item = 0 (RED 아님). 골든테스트가 0-default로 <1% 일치 확인.

## 6. Validator 룰 스펙 (handoff → stage 3)

`kics-json-validation-rules.md`에 신규 룰 추가. `8_life`를 그대로 복제·치환.

### Rule `19_market` — Market sub-risk (M diversification)

**Formula:** `item19 = sqrt(V' · M · V)`, `V = [36, 37, 38, 39, 40]` (순서 고정: 금리·주식·부동산·외환·자산집중).

**M:** §2 행렬. 구현: 대각 1.0, 외환-주식 −0.25, 자산집중 행/열 0(대각 제외), 그 외 비대각 0.25. (음내적 클램프 후 sqrt — 기존 diversified helper 재사용.)

**Prerequisites:** item19 present. items 36–40은 **있는 것만** 사용, 없으면 0 (생보 Rule 2의 `_sum_optional` 패턴; 5종 모두 없으면 SKIP).

**Tolerance:** **dynamic** `max(eff_tol, 0.05 * abs(expected))` — `8_life`와 동일 근거(5개 하위 반올림 누적). 이미지-only 회사(KR0010, KR0079)는 기존 10.0 오버라이드 승계.

**Missing inputs:** item19 없거나 36–40 전부 없음 → **SKIP** (RED 아님). 일부만 있음 → 있는 값으로 계산(없는 건 0). ← 8_life는 "전부 있어야"지만, 시장위험은 부동산/자산집중 정상 결측(미보유)이 흔하므로 **부분 허용**으로 완화.

**단위:** 파서가 item36–40을 억원으로 적재하면 item19와 동일단위 → 변환 불필요. 백만원으로 적재 시 `sqrt(V'MV)`(백만원)를 `item19×100`과 대조.

## 7. 금리위험액 2차 분해 — 시나리오별 순자산가치 (items 41–46)

item36(금리위험액)을 한 단계 더 분해. 단, 저장 primitive는 시나리오별 **위험액이 아니라 순자산가치**다 — 모든 공시형식에서 공통으로 나오는 원천값이기 때문(아래 형식 (A)(B) 모두 순자산가치 행 보유).

### 7-1. 마스터 합산식 (해설서 4-2.(6), p.209 — 확정)

```
금리위험액 = √[ max(금리상승위험액, 금리하락위험액)² + max(금리평탄위험액, 금리경사위험액)² ] + 평균회귀금액
```

- **2축 구조:** 수준(level)={상승,하락}, 기울기(slope)={평탄,경사}. 각 축에서 max → 두 축을 피타고라스 합성(축 간 상관 0) → +평균회귀금액(√ **밖**, 부호 자유·음수 가능).
- 시나리오 정의: 상승=기간구조 전반↑(LTFR+15bp), 하락=전반↓, 평탄(flattening)=단기↑장기↓, 경사(steepening)=단기↓장기↑, 평균회귀=장기평균 회귀(금리위험 증감 양방향).

### 7-2. 순자산가치 → 시나리오 위험액 유도 (★ 핵심)

공시는 시나리오별 **순자산가치**(충격 전 base + 5시나리오 충격 후)를 준다. 위험액은 유도:

```
시나리오위험액(상승/하락/평탄/경사) = max( 순자산가치_충격전(base) − 순자산가치_시나리오, 0 )
평균회귀금액 = 순자산가치_충격전(base) − 순자산가치_평균회귀      ← max 없음, 부호 그대로
```

### 7-3. 공시 형식 두 가지 (순자산가치 행은 둘 다 보유)

- **(A) 직접형** (예: 신한라이프): `Ⅳ.금리위험액` 행에 시나리오별 위험액도 직접 기재. 순자산가치 행도 있음.
- **(B) 유도형** (예: 흥국화재·현대해상): `Ⅳ.금리위험액`은 총액만. 시나리오별은 순자산가치 행에서 §7-2로 유도.

→ **순자산가치 행(items 41–46)을 보편 primitive로 저장**하면 (A)(B) 무관하게 일관 검증.

### 7-4. 골든 (FY2025_Q4, 백만원 — diff≈0)

| 회사 | base | 평균회귀 | 상승 | 하락 | 평탄 | 경사 | 유도 금리위험액 | 공시 |
|---|---|---|---|---|---|---|---|---|
| 흥국화재 | 4,312,681 | −33,245 | 0 | 94,046 | 165,521 | 0 | **157,128** | 157,127 |

### 7-7. Validator 룰 `36_irr` (item36 = 금리위험액 검증)

**Formula:** `item36 = √[max(R상승,R하락)² + max(R평탄,R경사)²] + R평균회귀`
여기서 (base=item41):
- `R상승=max(41−43,0)`, `R하락=max(41−44,0)`, `R평탄=max(41−45,0)`, `R경사=max(41−46,0)`
- `R평균회귀 = 41−42` (signed, no max)
